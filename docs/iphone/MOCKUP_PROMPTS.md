# Polished Mockup Prompts

These prompts document the built-in image-generation requests used for the static visual concepts. The interactive wireframe and `PRODUCT_SPEC.md` remain authoritative when generated text or geometry differs.

## Shared direction

Use case: `ui-mockup`

Create a realistic, high-fidelity native iPhone interface concept for **Beat Surfer Pro**, a live music-video performance instrument. The visual language is dark, focused, tactile, and professional: near-black graphite surfaces, restrained electric-cyan active states, warm red recording state, crisp off-white typography, subtle separators, compact radii, and no decorative glassmorphism. It should feel like a contemporary music-performance tool designed for iOS, not a desktop dashboard squeezed onto a phone. Use believable video thumbnails and precise compact controls. No device frame, hand, desk scene, marketing background, watermark, fake brand logo, gradients used as decoration, oversized headings, floating cards, or illegible invented paragraphs.
