# Portfolio case study

The original interactive Cursor canvas explaining Beatsmaxxer Pro's frame path,
shared timing, program monitor, and optional audio-analysis relay.

## Files

- [Canvas source](portfolio-case-study.canvas.tsx): the original presentation,
  including interactive pipeline diagrams and ownership tables.
- [Canvas state](portfolio-case-study.canvas.data.json): the saved view and
  selected stage.

These files were copied unchanged from the Mac's local Cursor project storage
on September 24, 2026 so they can travel with the repository through Git.
The original Cursor copy remains in place.

## Viewing and editing

The interactive presentation uses Cursor's `cursor/canvas` runtime. Open the
existing **Portfolio Case Study** canvas in Cursor to view it interactively.
The TSX source can be read in any editor; it is not a standalone browser page
or part of the Svelte app build.

Cursor's local canvas and these repository files are separate copies. After
editing the canvas in Cursor, copy its source and state back into this folder
and commit them to share the changes across machines.

This is a preserved presentation snapshot, not a fresh verification of every
implementation claim. For current architecture, see
[the architecture guide](../../svelte/docs/ARCHITECTURE.md).
