Recommended changes for Beatsmaxxer

Tier 1 Low risk, latency / maintainability

  • Split bind groups by frequency (Toji / FreeCut pattern): static sampler group + per-frame uniform/feedback/external group — cuts descriptor work across 8 previews + PGM.
  • Extract wgslLib.ts from moduleFx.wgsl.ts with golden shader snapshots (Beatform proves zero-drift testing).
  • requestVideoFrameCallback on slots not tied to audio fixed-step — decode cadence vs blind rAF (webgpu-samples).
  • Import pass destRect uniform for slot aspect-fit (FreeCut) — GPU-side crop/fit without canvas CSS hacks.

Tier 2 Determinism + QA

  • Port Beatform FixedFeedbackClock — unify feedback age with timeline.fixedStepIndex for export/QA determinism.
  • Timestamp queries behind __BMX_QA__ — per-module FX pass timing (webgpu-samples timestampQuery).
  • GPU histogram scope for QA autoload — compute aggregate only, no readback (webgpu-video-rendering scopes).
  • Frame-drop guard optional when queue saturated — gpuFrameBusy pattern from video-rendering demo.

Tier 3 Future architecture

  • ISF import path — Ghost Arcade parser for user shader slots (AGPL: reimplement API, don’t copy code).
  • ExternalCopyPipeline for modules needing >1 pass on live external texture.
  • Pipeline cache if we add per-user WGSL (Beatform WeakMap keyed by preset object).
  • Render bundles for stable blit pass when canvas size unchanged.
  • WebCodecs + Mediabunny frame path for frame-accurate scrub (FreeCut) — only if HTMLVideo latency becomes limiting.

What we already do well

Peer review confirms Beatsmaxxer’s core bets are correct: uber-shader + effectMode (one compile, eight modules), per-task importExternalTexture with idle texture_2d fallback, feedback ping-pong with degraded catch-up on stutter, and audio-master transport via single AppLoop. No React re-architecture needed — port WGSL and WebGPU API patterns only.

Skip list

  • C++/WASM compositor paths (OpenCut Rust rewrite) unless export-grade offline render becomes a goal.
  • Three.js WebGPURenderer — conflicts with WebGPU-only mandate.
  • Direct AGPL code copy from Ghost Arcade — study patterns, MIT-clean reimplementation.
  • Subgroups / multi-draw indirect — no win for eight fullscreen quads today.
